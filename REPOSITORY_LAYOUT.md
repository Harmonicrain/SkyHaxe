# Repository layout

The root working surface has one supported client project and one build command.

| Path | Ownership |
|---|---|
| `project.xml` | Sole supported OpenFL composition. |
| `scripts/build.ps1` | Supported compile/package command. Never regenerates Haxe. |
| `scripts/serve-client.py` | Local server for the packaged client and configured runtime corpus. |
| `client/` | Browser host and configuration template. |
| `src/` | Hand-maintained browser/OpenFL seams. |
| `.skyhaxe/generated/` | Reproducible AS3-to-Haxe output consumed by the build. |
| `.skyhaxe/platform/` | Reproducible patched platform output consumed ahead of libraries. |
| `.skyhaxe/compat/` | Converter compatibility runtime. |
| `build-support/generation/` | Conversion rules, closures, hashes and guarded patches. |
| `build-support/assets/` | Build-time indexes into the original clean-client asset corpus. |
| `build-support/platform/` | Tracked compile-time platform overrides. |
| `public/` | Runtime browser payloads and Truffle resources. |
| `test/` | Retained semantic regression sources. |
| `historical/` | Superseded projects, probes, tooling, evidence and narrative documents. |
| `build/client/html5/bin/` | Deployable output; generated by `scripts/build.ps1`. |

The [`wired2-ngh` Habbo-Sky branch](https://github.com/habbo-cc/Habbo-Sky/tree/wired2-ngh) is
authoritative for AS3 and build-time embedded assets.
The separately supplied runtime SWF/gamedata corpus is selected through
`SKYHAXE_RUNTIME_ROOT` or `serve-client.py --runtime-root`. Neither external corpus is owned or
deleted by this repository.

Normal development builds current Haxe directly. Regeneration is an explicit isolated operation
through `build-support/generation/reproduce.py`; it cannot overwrite `.skyhaxe/` by default.
Intentional upstream changes use `scripts/update-client.ps1`, produce an isolated candidate, and
require finalization plus explicit promotion before changing `.skyhaxe/`.
